## Idea

Upgrade the Cortex README (https://github.com/calenwalshe/cortex) to accurately reflect the current state of the system. The existing README covers the 16-command surface and layer architecture but understates or omits several capabilities that now exist: (1) the adjacent discovery mechanisms (IC Outside-In, assumption indicators, VOI filter), (2) depth-scaled research with 3 tiers, (3) HITL gate templates, (4) the knowledge engine (.cortex/facts.jsonl), (5) full autonomy system depth (13 gates, 4-layer resolution, dry-run mode), (6) repair loop semantics (bounded, convergence-aware), (7) 4 specialized agents with role-based write scopes, (8) 17 hook scripts, (9) doc drift detection, (10) /cortex-ship and /cortex-intent commands not in the table, (11) experiment mode for bounded hypothesis testing. The README structure (problem → solution → quick start → structure → upstream) is good but needs content refresh. The command table lists 14 commands but should list all 16. The structure tree is slightly stale. Goal: make the README an accurate, compelling representation of Cortex as it exists today without inflating or over-documenting — keep it a README, not a manual.
