<feature>
  <name>operational-indexer.py --summary mode</name>
  <files>scripts/cortex/operational-indexer.py, test/test_operational_indexer.py</files>
  <behavior>
    --summary mode reads the ledger (default: .cortex/edit-ledger.jsonl), aggregates, and outputs JSON to stdout.

    Flags:
      --ledger <path>   Override ledger path (default: .cortex/edit-ledger.jsonl). Required for test isolation.
      --min-count N     Minimum edit_count threshold for hotspots (default: 2)
      --top-files N     Max hotspot entries in output (default: 20, 0 = unlimited)
      --top-pairs N     Max co_change_pairs entries in output (default: 20, 0 = unlimited)

    Output JSON schema:
    {
      "hotspots": [{"file_path": "str", "edit_count": N}],   // sorted by edit_count desc
      "co_change_pairs": [{"files": ["a", "b"], "session_count": N}],  // sorted by session_count desc
      "entry_count": N,       // total ledger entries read (before any filtering)
      "as_of": "ISO8601Z",    // timestamp of invocation
      "caveat": "co-change pairs are session-scoped; /clear within a task will split the session and undercount coupling"
    }

    If ledger absent: output JSON with empty hotspots/co_change_pairs, entry_count: 0, plus "ledger_absent": true. Exit 0.

    Hotspot aggregation:
      - Count appearances of each file_path across ALL ledger entries
      - Filter: only include file_paths with edit_count >= min_count

    Co-change pair derivation:
      - Group entries by session_id
      - For each session with ≥2 unique file_paths, enumerate all unordered pairs
      - Count how many sessions each pair co-appears in
      - Output pairs sorted by session_count desc
      - Pairs where files == [f, f] are excluded (same file twice in one session)

    Cases: input JSONL → expected output
      3 sessions × 5 files, /f0 and /f1 appear in all 3 sessions → hotspots includes both (edit_count ≥ 3), co_change_pairs includes (/f0, /f1) with session_count == 3
      file with edit_count == 1 + default min_count 2 → NOT in hotspots
      file with edit_count == 1 + --min-count 1 → IS in hotspots
      fixture: 502 entries (3 sessions, 5 files cycling) → entry_count == 502 (reads all entries before filtering)
  </behavior>
  <implementation>
    Replace the NotImplemented --summary stub from Plan 01 with the real implementation.
    Use collections.Counter for edit_count aggregation.
    Use collections.defaultdict(set) for session→files grouping.
    Use itertools.combinations(sorted(files), 2) for pair enumeration.
    Use collections.Counter for pair session_count counting.
    No pip dependencies — stdlib only.
    Exit 0 always.
  </implementation>
</feature>
