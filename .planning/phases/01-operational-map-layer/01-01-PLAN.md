<feature>
  <name>operational-indexer.py --hook mode</name>
  <files>scripts/cortex/operational-indexer.py, test/test_operational_indexer.py</files>
  <behavior>
    --hook mode reads JSON from stdin (PostToolUse payload), extracts tool_name and tool_input.file_path.

    Filter: only proceed if tool_name in ("Edit", "Write"). All other tool names → exit 0, no ledger write.

    If tool_name is Edit or Write:
      - Read session_id from payload (top-level field)
      - Read file_path from payload["tool_input"]["file_path"] — soft-fail to "" if missing
      - Read slug from .cortex/state.json → "slug" field — soft-fail to "" if absent or malformed
      - Append one line to .cortex/edit-ledger.jsonl:
        {"timestamp": "ISO8601Z", "session_id": "...", "file_path": "...", "tool_name": "Edit|Write", "slug": "..."}
      - After append, read all lines; if count > 500, keep only last 500 (oldest dropped); rewrite file
      - Exit 0

    Exit 0 ALWAYS. Wrap everything in try/except — log warnings to stderr only, never raise.

    Schema contract for each JSONL entry (all fields required, all strings):
      timestamp: ISO 8601 UTC (datetime.utcnow().strftime("%Y-%m-%dT%H:%M:%SZ"))
      session_id: from payload["session_id"], default ""
      file_path: from payload["tool_input"]["file_path"], default ""
      tool_name: "Edit" or "Write"
      slug: from .cortex/state.json["slug"], default ""

    Cases: input → expected behavior
      {"tool_name": "Edit", "tool_input": {"file_path": "/tmp/x.py"}, "session_id": "s1", "cwd": "..."} → 1 line appended
      {"tool_name": "Write", "tool_input": {"file_path": "/tmp/y.py"}, "session_id": "s1", "cwd": "..."} → 1 line appended
      {"tool_name": "Bash", "tool_input": {"command": "ls"}, "session_id": "s1", "cwd": "..."} → no line appended
      {"tool_name": "Read", "tool_input": {"file_path": "/tmp/z.py"}, "session_id": "s1", "cwd": "..."} → no line appended
      502 entries written → exactly 500 remain (oldest 2 dropped)
  </behavior>
  <implementation>
    Follow structural-indexer.py as a structural pattern (argparse, exit 0 always, CORTEX_ROOT, stdlib only).
    Use argparse with --hook and --summary subcommands (stub --summary as NotImplemented placeholder for now).
    Include --ledger flag to override ledger path (default: .cortex/edit-ledger.jsonl) — needed for test isolation.
    CORTEX_ROOT = os.path.dirname(os.path.dirname(os.path.dirname(os.path.abspath(__file__))))
    DEFAULT_LEDGER = os.path.join(CORTEX_ROOT, ".cortex", "edit-ledger.jsonl")
    STATE_PATH = os.path.join(CORTEX_ROOT, ".cortex", "state.json")
  </implementation>
</feature>
