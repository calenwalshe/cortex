# Phase 23 Plan 01: Codex Execution Wrapper

## Objective

Build `scripts/cortex/codex-exec-wrapper.sh` handling the full Codex task lifecycle: worktree creation, capsule generation, Codex invocation with timeout, JSONL parsing for token usage, result validation against task-result schema, worktree merge on success / cleanup on failure, and token ledger write. All failures reclassify to claude-required with no Codex retries.

## Tasks

<task id="1" type="auto">
<name>Create codex-exec-wrapper.sh</name>
<action>
Create scripts/cortex/codex-exec-wrapper.sh implementing the full 9-step Codex execution lifecycle:

1. Parse arguments (PLAN_PATH, TASK_ID, TASK_JSON from task-router output)
2. Resolve paths: CORTEX_ROOT (script dir/../..), SCHEMA_PATH, CAPSULE_TEMPLATE, PRICING_PATH
3. Create git worktree: `git worktree add /tmp/gsd-codex-{phase}-{plan} -b codex/{phase}-{plan}`
4. Generate capsule: populate task-capsule.md template with task data + file context (capped at 12KB)
5. Invoke Codex: `cat capsule.md | timeout ${TIMEOUT} codex exec --full-auto --json -C /worktree -` with tee to JSONL log
6. Parse JSONL output: extract token usage from turn.completed events, extract result JSON from final assistant message
7. Validate result: check status field, tests_passed, commit_hash presence
8. On success (status=complete, tests_passed=true): merge worktree branch into current branch, cleanup
9. On any failure: cleanup worktree, output failure JSON for Claude fallback

Failure handling (every failure reclassifies to claude-required):
- Timeout (exit 124): merge any committed work from worktree, reclassify remainder
- Tests fail (tests_passed:false): delete worktree, pass failure context
- Checkpoint (status:checkpoint): delete worktree, pass checkpoint_detail
- JSONL parse error: check for commits in worktree, reclassify
- Merge conflict (git merge non-zero): delete worktree, reclassify
- Process crash (non-zero, non-124 exit): log stderr, delete worktree, reclassify

Timeout tiers (from 23-CONTEXT.md):
- TDD tasks: 180s
- Auto with <5 files: 300s
- Auto with 5-8 files: 450s

Token ledger write: INSERT into codex_tasks table after execution with summed token usage.

Output: JSON on stdout conforming to a wrapper result format:
{
  "status": "complete|failed|fallback",
  "task_id": "...",
  "result": { ...task-result fields... },
  "tokens": { "input": N, "output": N, "cached": N, "reasoning": N },
  "cost_usd": N,
  "elapsed_ms": N,
  "fallback_reason": null|"timeout"|"test_failure"|"checkpoint"|"parse_error"|"merge_conflict"|"crash"
}
</action>
