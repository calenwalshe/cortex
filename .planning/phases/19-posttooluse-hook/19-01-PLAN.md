claude_turns schema:
  id INTEGER PRIMARY KEY AUTOINCREMENT
  ts TEXT NOT NULL DEFAULT (strftime('%Y-%m-%dT%H:%M:%fZ', 'now'))
  session_id TEXT NOT NULL
  message_id TEXT NOT NULL UNIQUE
  model TEXT NOT NULL

  phase TEXT
  skill TEXT
  remaining_pct REAL

  session_id TEXT PRIMARY KEY
  started_at TEXT NOT NULL DEFAULT (now)
  ended_at TEXT
  project_slug TEXT
  model TEXT
  compacted INTEGER NOT NULL DEFAULT 0
  total_input INTEGER NOT NULL DEFAULT 0
  total_output INTEGER NOT NULL DEFAULT 0
  total_cost REAL NOT NULL DEFAULT 0.0

daily_rollup schema:
  (date, provider, model, project_slug, phase) PRIMARY KEY
  input_tokens, output_tokens, cost_usd, turn_count

PostToolUse hook stdin JSON contract (from Claude Code):
  session_id: string
  cwd: string (via data.cwd or process.cwd())
  model: { display_name: string }
  context_window: { remaining_percentage: number }
  tool_name: string (the tool that was just used)

Session JSONL transcript location:
  ~/.claude/projects/{project_dir_slug}/{session_id}.jsonl
  project_dir_slug = cwd path with / replaced by - (e.g., -home-agent-projects-cortex)

JSONL assistant message format (type="assistant"):
  message.id = message_id (e.g., "msg_01XVhMrpHjs3Cbhe8QiLr6BW")
  message.model = model name (e.g., "claude-opus-4-6")
  message.usage = {
    input_tokens, output_tokens,
    cache_creation_input_tokens, cache_read_input_tokens,
    server_tool_use (present on final message for a turn),
    service_tier, inference_geo, iterations, speed
  }
  NOTE: Each message_id appears TWICE in the transcript — first with partial
  usage (streaming start), then with final usage (has server_tool_use, iterations,
  speed fields). The hook should use the LAST occurrence of each message_id.

Existing PostToolUse hook pattern (gsd-context-monitor.js):
  - Reads stdin JSON, parses with timeout guard
  - Uses 10s stdin timeout, exits 0 on any error
  - Returns hookSpecificOutput.additionalContext if needed
  - Silent exit(0) on all error paths

**2. Create `hooks/token-ledger.js`:**

Follow the exact pattern from gsd-context-monitor.js for stdin reading (10s timeout, UTF-8, exit 0 on any error). The hook:

a. **Stdin parsing:** Read JSON from stdin. Extract `session_id`, `cwd` (fall back to process.cwd()), `context_window.remaining_percentage`, `tool_name`.

b. **Transcript path resolution:** Compute project dir slug from cwd: replace leading `/` then all `/` with `-`. Build path: `~/.claude/projects/{slug}/{session_id}.jsonl`. If file doesn't exist, exit 0.

c. **Tail-read last 8KB:** Use `fs.openSync` + `fs.readSync` with calculated offset (`stat.size - 8192`, min 0). Split on newlines, parse each as JSON.

d. **Extract last assistant turn:** Filter for lines where `type === 'assistant'`. Group by `message.id`. For each message_id, keep the last occurrence (which has complete usage with `server_tool_use` field). Take the overall last unique message_id as the current turn.

e. **Dedup check:** Read `/tmp/ledger-last-{session_id}` (single line: last recorded message_id). If current message_id matches, exit 0. Otherwise write new message_id to that file.

f. **Cost computation:** Load `pricing.json` (use `require()` with path relative to `__dirname` → `../scripts/cortex/pricing.json`). Look up model. Compute:
   ```
   cost = (input_tokens * pricing.input)
        + (output_tokens * pricing.output)
        + (cache_creation_input_tokens * pricing.cache_write)
        + (cache_read_input_tokens * pricing.cache_read)
   ```
   Fall back to `_default` pricing if model not found.

g. **Phase extraction:** Try to read `{cwd}/.planning/STATE.md`. Regex for `^Phase:\s*(.+)$` (multiline). Use captured group or null.

h. **Project slug extraction:** Use the transcript directory name (the slug computed in step b).

i. **DB write (single transaction):** Open `~/.cortex/token-ledger.db` via better-sqlite3 (respect `TOKEN_LEDGER_DB` env var). In one transaction:
   - INSERT INTO claude_turns (session_id, message_id, model, input_tokens, output_tokens, cache_creation_tokens, cache_read_tokens, cost_usd, project_slug, cwd, phase, skill, remaining_pct) VALUES (...)
     - `skill` = tool_name from hook input
     - `remaining_pct` = context_window.remaining_percentage
   - INSERT OR IGNORE INTO sessions (session_id, project_slug, model) VALUES (...)
   - UPDATE sessions SET total_input = total_input + ?, total_output = total_output + ?, total_cost = total_cost + ? WHERE session_id = ?
   - INSERT INTO daily_rollup ... ON CONFLICT(date, provider, model, project_slug, phase) DO UPDATE SET input_tokens = input_tokens + ?, output_tokens = output_tokens + ?, cost_usd = cost_usd + ?, turn_count = turn_count + 1
     - `provider` = 'claude', `date` = strftime('%Y-%m-%d')

j. **Compaction detection:** If `remaining_pct` is available, read previous remaining_pct from `/tmp/ledger-last-{session_id}` (store alongside message_id as JSON: `{mid, pct}`). If current pct > previous + 30, UPDATE sessions SET compacted = 1.

k. **Output:** Exit 0 with no stdout (hook has no additional context to inject). The hook is async so it doesn't need to return output.

**Error handling:** Wrap everything after stdin parse in try/catch. On ANY error (missing DB, missing transcript, parse failure, sqlite error), exit 0 silently. Never block tool execution. If better-sqlite3 cannot be loaded (not installed), exit 0 immediately with no error.

**Performance target (TE-05):** The combination of tail-read (O(1)), dedup check (1 file read), and better-sqlite3 transaction (~0.5ms) should complete in <5ms total.
