### New functions spec (from decisions)

**`build_communication_judge_prompt(message_text, rubric)`**
- System prompt must declare "communication quality judge" (not "code quality judge")
- Include all 5 dimensions with 0-4 scale
- Include explicit rejection rule: `calibrated_uncertainty < 2 → FAIL regardless`
- Include aggregate threshold: mean normalized to 0-1; >= 0.7 to pass
- Output JSON schema: `{verdict, per_dimension_scores, aggregate_score, critique}`

**`judge_communication(message, rubric_path, max_retries=3)`**
- Load rubric from YAML file (use PyYAML or stdlib — check existing imports first)
- Loop: call `build_communication_judge_prompt` → call `call_judge` → parse result
- Apply rejection rule: if `calibrated_uncertainty < 2`, force verdict=FAIL
- Apply aggregate: mean of per_dimension_scores / 4.0 (scale); if >= 0.7, verdict=PASS
- On FAIL: build critique-guided rewrite prompt → call `call_judge` for rewritten message → retry
- On retry cap exhaustion: return escalation struct `{verdict: "ESCALATE", original_message, final_rewrite, critique, attempts}`
- Write JSONL entry on every attempt (attempt 1 = original, attempt 2+ = rewrites)
- JSONL path: `~/.cortex/calibration/comm-judge-{rubric_hash}.jsonl`
- JSONL schema fields: `timestamp, slug, surface, judge_model, rubric_hash, original_message, rewrite_attempt, per_dimension_scores, aggregate_score, verdict, critique, rewrite_diff, confidence, calibration_corrections_applied`

  ```python
  def build_communication_judge_prompt(message_text, rubric):
      """Build judge prompt for communication quality evaluation."""
      dimensions = rubric.get('dimensions', [])
      dim_text = '\n'.join(
          f"  - {d['name']} (0-{d['scale']}): {d['description']}"
          for d in dimensions
      )
      return f"""You are a communication quality judge evaluating an AI-generated summary for an owner.

  REJECTION RULE: If calibrated_uncertainty < 2, verdict MUST be FAIL regardless of other scores.

  DIMENSIONS (score 0-4 each):
  {dim_text}

  AGGREGATE THRESHOLD: mean of dimension scores normalized to 0-1 (divide by 4); >= 0.7 to pass.

  OUTPUT: Respond ONLY with JSON (no markdown):
  {{"verdict": "PASS" or "FAIL", "per_dimension_scores": {{"clarity": <0-4>, "actionability": <0-4>, "evidence_traceability": <0-4>, "completeness": <0-4>, "calibrated_uncertainty": <0-4>}}, "aggregate_score": <float 0.0-1.0>, "critique": "<what specifically failed and why>"}}

  MESSAGE TO EVALUATE:
  {message_text}"""
  ```
