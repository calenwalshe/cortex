# Phase 20 Plan 01: Token Report CLI

## Objective

Create `scripts/cortex/token-report.sh` — a CLI query tool that runs formatted SQL reports against the token ledger (`~/.cortex/token-ledger.db`) and optionally ATTACHes power-search usage DB for cross-source analysis. Satisfies TE-06.

## Context

- @scripts/cortex/create-token-ledger.sh (schema: claude_turns, codex_tasks, sessions, daily_rollup)
- @docs/cortex/research/token-efficiency/implementation-20260402T225932Z.md (Section B: Query Interface — Q1-Q7)
- @scripts/cortex/pricing.json (per-model cost rates)
- @.planning/phases/20-token-report-cli/20-CONTEXT.md (phase boundary + decisions)

## Tasks

<task id="1" type="auto">
<name>Create token-report.sh with 7 report queries</name>
<action>
Create scripts/cortex/token-report.sh with:
- DB_PATH defaults to ~/.cortex/token-ledger.db (overridable via TOKEN_LEDGER_DB)
- ATTACH ~/.power-search/usage.db if it exists (for cross-source joins)
- 7 formatted reports: daily cost, phase cost, skill cost, cache hit ratio, session ranking, context burndown, cost by provider
- Flag interface: --today (today only), --phase X (filter by phase), --session Y (filter by session), --report NAME (run single report), no flags = all reports
- Human-readable formatted output with aligned columns
- set -euo pipefail, DB existence check with actionable error
</action>

</task>
