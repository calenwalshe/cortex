# Roadmap: clarify-research-loop

## Overview

Implement a pilot of the seven-terminal-state model for the Cortex pre-spec phase, layered as a refinement on top of the existing `/cortex-spec` necessity gate (BUILD/NARROW/DEFER/REJECT) without modifying the necessity gate itself. The pilot consists of: (1) a mandatory `--terminal {name}` flag on `/cortex-close` that records which of seven terminal states a slug closed at, (2) a new `current-understanding.md` artifact template auto-generated by `/cortex-clarify` from the brief's `initial_terminal_set` frontmatter, and (3) a documented vocabulary of seven terminals with mapping to existing necessity-gate verdicts. A pre-pilot retroactive audit of historical necessity verdicts is a hard gate before any code is written. The slug dogfoods the new flow on itself by closing via `/cortex-close --terminal commit-to-build` once complete.

## Phases

### Phase 1: Pre-pilot Retroactive Audit (HARD GATE)

**Goal**: Validate the 4→7 refinement empirically against historical necessity-gate verdicts BEFORE writing any code. If the audit fails, stop the pilot and re-clarify.
**Depends on**: Nothing
**Requirements**: None formalized
**Success Criteria** (what must be TRUE):
  1. Retroactive audit results file exists with complete table of historical non-BUILD necessity verdicts and their proposed terminal mapping
  2. Audit pass criterion met: ≥60% of historical non-BUILD verdicts map cleanly with confidence ≥0.7
**Research**: Unlikely (audit reads existing decisions.md only)
**Plans**: 0 plans

### Phase 2: Templates

**Goal**: Add the new `current-understanding.md` template and document the brief frontmatter convention. No skill changes yet — pure additive template work.
**Depends on**: Phase 1
**Requirements**: None formalized

### Phase 3: Skill Modifications

**Goal**: Add Phase 4b to `/cortex-clarify` (auto-write current-understanding.md) and `--terminal {name}` flag to `/cortex-close` (with validation and decisions.md format extension). Both skills exist in two locations that must be kept byte-identical.
**Depends on**: Phase 2
**Requirements**: None formalized
**Success Criteria** (what must be TRUE):

  2. Both copies of `cortex-close` SKILL.md require `--terminal {name}` flag with validation against the seven values and against brief's `ruled_out:` list
  3. `decisions.md` Archive Index format includes `terminal:` field with updated format comment
**Research**: Unlikely
**Plans**: 0 plans

### Phase 4: Documentation

**Goal**: Add §7 Terminal States to DISCOVERY_LOOP.md with the 4→7 refinement mapping, cross-referenced from existing sections. This is the canonical reference for the new vocabulary.
**Depends on**: Phase 3
**Requirements**: None formalized
